# CDS UI glossary — 2026-08-26

The primary interface uses the wording below. API fields, rule IDs, audit events, and
legal/business semantics keep their existing internal names.

| Internal term | User-facing wording |
|---|---|
| Conditions Precedent / CP | Approval requirements |
| CP open | Approval requirement outstanding |
| Findings / Exception | Issues |
| OCR complete | Text extracted |
| Processing | Analyzing documents |
| Needs review | Review required |
| Use as fact | Accept this value |
| Attach as evidence | Link this page as proof |
| Process new evidence | Analyze uploaded documents |
| Decide | Record decision |
| Blocked by | What is stopping approval |
| Next | Next step |
| Draft pack preview | Preview approval pack |
| Waive | Request a waiver |
| Resolve | Mark issue resolved |

Copy order on a Matter page:

1. What am I looking at?
2. What has happened?
3. What is preventing progress?
4. What should I do next?
5. What secondary actions are available?
6. What technical detail can I inspect if needed?
